# Qaqeibo 仕様書 / 設計書

## 1. 概要 (Overview)
* **アプリ名**: Qaqeibo
* **プロダクトの目的**: 家計の動向の細やかな統計をわかりやすい形で分析して提供する
* **ターゲットユーザー**: 情報系の知識があり、自分の家計の出納をきちんと管理/分析したい人
* **主要な価値（コアバリュー）**: 消費の種類のラベル付けで消費の傾向を掴む。プログラミングによって自分でも分析しやすいようcsv形式で入力、出力できるようにする。

## 2. 要件定義 (Requirements)
### 2.1. 機能要件 (Functional Requirements)
* **F-01 入力**: 収入/支出の入力
  * 詳細: 収入と支出についてそれぞれ年月日、消費の種類のラベル、用途、金額を記録できるようにする。用途では表記揺れを防ぐため、過去の用途を元にしたサジェストを実装する。例)「せぶ」→「セブンイレブン」。金額は正の整数。
* **F-02 検索・閲覧**:収入/支出の閲覧
  * 詳細: 収入と支出についてそれぞれ月ごとに表示させる。
* **F-03 検索・閲覧**:収入/支出の統計
  * 詳細: 収入と支出についてそれぞれ月ごとに合計、ラベルごとの合計、ラベルごとの消費を円グラフで表示する
* **F-04 出力**:データの出力
  * 詳細: csv形式で出力し、ダウンロードできるようにする。保存先は「書類>Qaqeibo>output」月ごとやラベルごとなど範囲を絞って出力できるようにする。
* **F-04 出力**:データの入力
  * 詳細: csv形式でデータを追加できるようにする。Finderから入力のためのファイルを選択させるようにする。
  

### 2.2. 非機能要件 (Non-Functional Requirements)
* **対応環境・プラットフォーム**: Macbook
* **パフォーマンス・レスポンス**: 全ての操作が1秒以内に終わって欲しい
* **セキュリティ・認証**: ネイティブアプリのため必要なし
* **拡張性・保守性**: ファイルはモジュールごとになるべく分割する。ユーザーの全ての操作に対しログを出力し、操作対象のデータの量(行数)を出力

* **データモデル / エンティティ定義**: 
expenditure{
  uuid: id,
  Date: date,
  enum String: Rabel,
  String: purpose,
  int: amount
}
income{
  uuid: id,
  Date: date,
  enum String: Rabel,
  String: source,
  int: amount
}
